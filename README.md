# Community Portal — Demo

A static demo of the **Community Portal** ("HOPE Portal") — a community website mockup
covering members, jobs, matrimony, store, services, links, about, contact and registration.

> **Demo only.** This is a front-end mockup. There is no backend or database —
> the registration form shows a success message but does not store any data.
> Member/team/product photos use [placehold.co](https://placehold.co) placeholders.

## Tech
- Plain HTML + [Tailwind CSS](https://tailwindcss.com) (via CDN)
- Font Awesome icons (via CDN)
- No build step required

## Run locally
Any static file server works, e.g.:

```bash
python3 -m http.server 8099
# then open http://localhost:8099
```
